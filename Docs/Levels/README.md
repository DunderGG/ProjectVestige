# Level design documentation

This folder holds level blockout plans and editor notes. These documents describe proposed layouts; they do not change the Unreal maps or establish new gameplay. Unreal map assets remain under `Content/Maps/`.

## Home farm

- [Home farm plan](./HomeFarm/README.md): the layout of `/Game/Maps/L_Farm` for the vertical slice, with what is fixed, size targets in walking time, the build order and when it is done.
- [Home farm diagram](./HomeFarm/HomeFarm.svg): a top-down sketch of that plan, drawn to the targets; the map, not the drawing, is the measurement.

## Shared level-authoring tools

- [Reusable level tools](./Scripts/README.md) describes the implemented read-only survey (in-Editor validation pending) and proposals for blockout generation, optional adjustment widgets, and route validation.
