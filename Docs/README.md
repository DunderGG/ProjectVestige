# Documentation

This folder contains project documentation for setting up, designing, building, testing, and contributing to Project Vestige. Most documents are spoiler-free; story and character material is kept in [`Spoilers/`](Spoilers/README.md).

## Project guides

| Document | Purpose |
|---|---|
| [`Setup.md`](Setup.md) | Set up a Windows development PC, build the project, and troubleshoot common problems. |
| [`Architecture.md`](Architecture.md) | Explain the design principles, system ownership, dependencies and data flow. |
| [`DecisionLog.md`](DecisionLog.md) | Record every design decision with its reasons, newest first. |
| [`Systems.md`](Systems.md) | Index of the system guides, one file per system in [`Systems/`](Systems/): implementation guidance for the game's systems and the Unreal Engine features they use. |
| [`CodingGuidelines.md`](CodingGuidelines.md) | Define C++ conventions, asset naming, testing, and code review expectations. |
| [`GameDesign.md`](GameDesign.md) | Describe the game's premise, intended experience, and gameplay design. |
| [`Roadmap.md`](Roadmap.md) | Track completed work and planned milestones. |
| [`PlayTest.md`](PlayTest.md) | List pending in-editor checks and the project's manual smoke test. |
| [`PlayTestArchive.md`](PlayTestArchive.md) | Keep the play-test checks that have all passed, as the record of what was checked by hand. |
| [`PerformanceBaseline.md`](PerformanceBaseline.md) | Record the performance baseline: each run on the benchmark scene, how it is measured and what it found. |

## Reviews and audits

| Document | Purpose |
|---|---|
| [`CodeReview.md`](CodeReview.md) | Record findings from a senior review of the game's code and architecture, with fixes tracked in the roadmap. |
| [`ArchitectureAudit.md`](ArchitectureAudit.md) | Record findings from an architecture review. |
| [`CodingGuidelinesAudit.md`](CodingGuidelinesAudit.md) | Record findings from a coding-guidelines review. |
| [`GameDesignAudit.md`](GameDesignAudit.md) | Record findings from a game-design review. |
| [`LicensingAudit.md`](LicensingAudit.md) | Record findings from a licensing review. |

[`Spoilers/`](Spoilers/README.md) contains the world's lore, characters, factions, story timeline, flow diagrams, and dialogue drafts. Its contents reveal planned story details.

For contribution workflow, art and audio pipelines, and data-driven content instructions, see the repository's [`CONTRIBUTING.md`](../CONTRIBUTING.md). Licensing terms are in [`LICENSING.md`](../LICENSING.md).
