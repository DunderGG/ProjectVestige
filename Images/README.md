# Images

This folder holds images used to introduce Project Vestige, illustrate its world, and support project documentation. These are presentation and reference materials; game assets that are imported into Unreal belong under `Content/`.

## Contents

As the project grows, group images into a subfolder when they serve a distinct purpose. Current categories include:

- `ConceptArt/` for exploratory ideas, mood pieces, and visual-development collections.
- `Screenshots/` for captures of the game in the editor or in play.
- `Promotional/` for posters, banners, and other materials prepared to present the project.
- `Reference/` for visual references used during development.

These are suggestions, not a required folder structure. Keep related materials together, use filenames that make their subject and purpose clear, and link to images with paths relative to the document that uses them.

Before adding an image, check its source and usage rights. Project-created assets and documentation are generally covered by CC BY-NC-SA 4.0; third-party material must have an accepted license and be recorded in [`CREDITS.md`](../CREDITS.md) and the path table in [`LICENSING.md`](../LICENSING.md).
