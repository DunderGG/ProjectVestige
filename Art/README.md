# Art source files

This folder contains the editable source files and export pipeline for the project's 3D art. It is not the folder for images used in documentation or promotion; those belong in [`Images/`](../Images/). Assets imported into Unreal belong under `Content/Vestige/`.

## Folders

- [`Blender/`](Blender/) contains `.blend` source files and scripts used to create or generate models.
- [`Export/`](Export/) contains FBX files exported from Blender, ready to import into Unreal.

Keep the Blender source for each imported model in the repository so it can be revised, and export FBX files to `Export/` using the naming and export settings in the [contributing art guide](../CONTRIBUTING.md#5-contributing-art).
